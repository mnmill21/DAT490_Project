# DAT490 Project: Analysis of U.S. Airline Cost Efficiency and Operational Performance

This repository contains code, data references, figures, and written reports for our DAT490 capstone project on airline cost efficiency and operational performance.

## Repository Structure
- `notebooks/`: Colab notebooks and Python scripts
- `data/`: raw and processed datasets
- `figures/`: exported visualizations used in reports and slides
- `reports/`: LaTeX drafts (project plan, literature review, methodology, EDA, results, and rough draft) and presentation materials

## Main Data Sources
- BTS T-100 Domestic Segment
- BTS Form 41 Schedule P-1.2
- BTS On-Time Performance dataset
- Kaggle-hosted OTP extract used for aggregation

## Notes
Large raw datasets may not be stored directly in this repository. See source references in the reports for download locations.
